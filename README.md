# java-racingcar-precourse

# [자동차 게임 기능]

## 구현할 기능 목록

### [입출력]

### 1. *입력(Input)

- [ ] 콘솔로부터 문자열 입력을 받는다.
- [ ] 콘솔부터 시도할 횟수를 입력 받는다.
- [ ] 추출한 입력값이 올바른지 검증
    + 추출한 입력값이 5자 이하인지 검증
    + 유효하지 않다면 `IllegalArgumentException`을 발생시킨다
- [ ] 입력받은 문자열을 (`,`)을 구분자로 이름을 분리한다.

### 2. *출력(Output)

- [ ] 차수별 실행 결과 출력
    + 실행 결과를 받아서 `name : ---`의 형식으로 출력( (`-`) 하나당 1의 전진)
- [ ] 최종 우승자를 출력
    + 최종 우승자 데이터를 받는다
    + 최종 우승자가 한명이면 그대로 출력. 복수라면 (`,`)를 이용하여 구분하여 출력

### 3. *랜덤 발생기(Random Number Generator)

- [ ] 0 ~ 9 의 숫자를 발생시킨다.

### 4. *경기(Game)

- [ ] 랜덤 발생기로 생성한 숫자를 받는다.
- [ ] 받은 숫자가 4이상인지 확인하고 적절하게 게임 상태를 업데이트한다.
- [ ] 최종 우승자를 구해낸다.
